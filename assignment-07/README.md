# 7차 과제

객체지향 프로그래밍 및 설계 수업의 C++ 과제다. 아래 요구사항은 제공된 코드와 예제를 기준으로 정리했으며 원래 과제 명세가 있는 경우 대조해야 한다.

## 1번. 정렬된 단어 리스트 병합

### 과제 요구사항

두 줄의 단어를 대소문자를 구분하지 않는 순서로 정렬하고 병합한다.

### 구현 시 필요한 OOP 및 C++ 개념

Node 클래스, 동적 문자 배열, 단일 연결 리스트.

### 구현 시 유의사항

한 줄은 4095자 이하이며 ASCII 영문 기준으로 대소문자를 비교한다. 원래 명세의 동률 순서는 별도 확인이 필요하다.

### 개선 및 보완

**수정본에 반영한 내용**

string을 제거하고 빈 단어를 건너뛴다. 기존 노드를 재연결하여 병합을 O(n+m)에 수행하고 모든 노드를 해제한다. 개별 리스트는 정렬 삽입을 유지한다.

## 2번. 문자열 토큰 분리

### 과제 요구사항

@와 .을 구분자로 입력 문자열을 나누어 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

정적 지역 포인터, 문자 배열과 포인터 반환.

### 구현 시 유의사항

입력은 99자 이하이다. 연속 구분자의 빈 토큰은 기존 동작을 유지한다.

### 개선 및 보완

**수정본에 반영한 내용**

보관 포인터를 초기화하고 첫 호출이 null인 경우를 검사한다. 입력 길이와 EOF를 확인한다.

## 3번. 연결 큐

### 과제 요구사항

지정 용량의 큐에서 push, pop, full, empty, print, exit를 처리한다.

### 구현 시 필요한 OOP 및 C++ 개념

연결 노드, 캡슐화, 소유권과 소멸자.

### 구현 시 유의사항

main.cpp와 Queue.cpp를 함께 빌드한다. Pop이 반환한 노드의 소유권은 호출자에게 넘어간다.

### 개선 및 보완

**수정본에 반영한 내용**

빠진 Queue.h를 구현과 호출 방식에 맞춰 작성했다. 초기 포인터·빈 큐를 검사하고 불필요한 복사 노드 생성을 없앴다. 꽉 찼을 때에도 push의 정수 입력을 소비하며 O(1) 삽입·삭제와 메모리 해제를 수행한다.

## 4번. 연결 스택

### 과제 요구사항

지정 용량의 스택 명령을 처리하고 역순으로 pop한다.

### 구현 시 필요한 OOP 및 C++ 개념

연결 노드, 양방향 연결, 객체 소유권.

### 구현 시 유의사항

main.cpp와 Stack.cpp를 함께 빌드한다. print는 기존처럼 삽입 순서로 표시한다.

### 개선 및 보완

**수정본에 반영한 내용**

빠진 Stack.h를 작성하고 이전 노드 연결로 삭제를 O(n)에서 O(1)로 바꿨다. 빈 스택·용량·EOF와 노드 해제를 처리한다.

## 빌드 및 확인

각 문제를 독립 실행 파일로 빌드한다. 같은 문제의 모든 .cpp를 함께 컴파일하고, 다른 문제의 소스는 섞지 않는다. 표준 컨테이너와 `<algorithm>`, `<utility>`, `<numeric>` 헤더는 사용하지 않는다. 입출력, C 문자열·숫자 변환, 수학, 예외 처리는 사용한다. 7차 4문제는 Visual Studio 2022 C++17로 빌드하고 대표 실행 사례를 확인했다. 전체 입력 영역의 정확성을 보장하는 것은 아니다.
