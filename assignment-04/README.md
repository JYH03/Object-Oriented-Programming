## 1번. 배열 기반 스택

### 과제 요구사항

push, pop, top, print, empty, exit 명령을 처리하는 스택을 구현한다.

### 구현 시 필요한 OOP 및 C++ 개념

배열 기반 LIFO 자료구조와 함수·상태 분리. 현재 코드의 클래스 사용 여부와 관계없이 스택의 캡슐화를 연습할 수 있다.

### 구현 시 유의사항

빈 스택에서 pop과 top을 수행하지 않도록 하고, 고정 배열이 가득 찬 경우를 확인한다.

### 개선 및 보완

용량 초과 및 잘못된 입력을 처리하고, 명령 처리와 스택 연산을 분리하는 방법을 검토한다.

**수정본에 반영한 내용**

스택이 가득 찬 상태에서 추가 입력이 배열 범위를 넘지 않도록 검사한다.


## 2번. 미로 최단거리

### 과제 요구사항

0과 1로 표현된 미로와 시작·도착 좌표를 입력받아 BFS로 최단 이동 거리를 찾는다.

### 구현 시 필요한 OOP 및 C++ 개념

구조체, 연결 큐, 동적 메모리, BFS와 방문 표시.

### 구현 시 유의사항

좌표의 1 기반/0 기반 변환과 실제 미로 크기, 벽과 방문 여부를 확인한다. 거리의 단위는 보고서 기준 칸 수다.

### 개선 및 보완

도착 불가능할 때의 출력을 명세와 대조하고 큐가 비는 경우, 경계, 동적 메모리 해제를 점검한다.

**수정본에 반영한 내용**

탐색 범위를 입력된 미로 크기로 제한하고, 큐가 비었을 때 `No path`를 출력한 뒤 종료하도록 했다. 출력 문구는 원래 명세와 대조해야 한다.


## 3번. 문자열·메모리 함수 구현

### 과제 요구사항

memset, memcpy, strcmp, strncmp, strcpy, strncpy, strlen, atoi, atof에 해당하는 기능을 직접 구현하고 표준 함수와 비교한다.

### 구현 시 필요한 OOP 및 C++ 개념

포인터, 배열, 문자열 종료 문자, namespace와 함수 인터페이스.

### 구현 시 유의사항

문자열 길이, 버퍼 크기, 종료 문자, 음수 및 소수 처리와 각 표준 함수의 실제 동작을 구분한다.

### 개선 및 보완

빈 문자열, 부호·공백, 복사 길이와 경계 사례를 표준 함수와 비교한다. 겹치는 메모리 영역 등 함수별 전제조건도 확인한다.

**수정본에 반영한 내용**

수정본은 `oopstd.h`를 사용한다. `strcpy`의 반환 주소, `strncmp`의 종료 문자 처리, `strncpy`의 나머지 칸 채우기를 수정하고 숫자 변환의 공백·부호 처리를 보완했다. 대표 사례를 확인했으며 모든 표준 함수 입력을 검증한 것은 아니다.


## 4번. 이진 코드 해독

### 과제 요구사항

[binary.txt](./4번/binary.txt)의 코드를 읽고, 0의 개수와 구분 규칙을 이용해 알파벳으로 변환한다. `binary.txt`가 있는 폴더에서 실행하면 결과가 `alphabet.txt`에 저장된다.

### 구현 시 필요한 OOP 및 C++ 개념

파일 스트림, 문자 코드, 배열과 입출력 상태.

### 구현 시 유의사항

문제에서 지정한 코드 규칙을 확인한다. 입력 파일이 작업 폴더에 있어야 하며 출력 파일은 생성 또는 덮어쓰기된다.

### 개선 및 보완

**수정본에 반영한 내용**

입력 또는 출력 파일을 열지 못하면 종료하고, 읽은 줄을 각각 처리하도록 바꾸었다. 두 줄 입력으로 출력을 확인했다.


## 라이브러리 사용에 관한 변경

표준 컨테이너나 알고리즘 유틸리티를 사용하지 않는다. 3번은 직접 구현한 함수와 표준 문자열 함수를 비교하는 과제이므로 비교용 표준 함수 호출은 유지했다. 원래 사용하던 입출력·수학 및 파일 처리 헤더는 유지하며 정확한 제한 범위는 과제 명세로 확인해야 한다.
