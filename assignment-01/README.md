## 1번. 시어핀스키 삼각형

### 과제 요구사항

단계 K를 입력받아 기본 삼각형 세 개를 반복적으로 배치하여 해당 단계의 삼각형을 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

2차원 문자 배열, 반복문, 함수와 배열 인덱스. 제출 코드는 클래스를 사용하지 않는다.

### 구현 시 유의사항

단계별 높이는 3×2^(K-1), 너비는 6×2^(K-1)-1이다. 고정 배열의 범위와 입력 실패를 확인한다.

### 개선 및 보완

문자 하나로 입력받으므로 여러 자릿수나 숫자가 아닌 값은 의도대로 처리되지 않는다. 640×640 배열을 넘는 단계와 입력 오류를 방지하도록 개선할 수 있다.

**수정본에 반영한 내용**

문자로 받은 단계가 1~7 범위 밖이면 종료하도록 했다. 고정 배열을 넘는 접근을 막는다.


## 2번. 이차방정식

### 과제 요구사항

보고서에 따르면 float 변수로 계수 a, b, c를 입력받고 실근 두 개, 중근, 실근 없음의 경우를 출력한다. a가 0이면 다시 입력받는다.

### 구현 시 필요한 OOP 및 C++ 개념

실수 자료형, 조건문, cmath의 제곱근과 부동소수점 오차. 현재 클래스는 없다.

### 구현 시 유의사항

판별식 b²-4ac의 부호를 먼저 확인하고, 입력 실패와 오차를 고려한다. 원래 과제의 float 제약을 유지한다.

### 개선 및 보완

현재 판별식 확인 전에 음수의 제곱근을 계산할 수 있다. 판별식 계산과 분기를 먼저 수행하고 입력 오류 처리를 추가한다.

**수정본에 반영한 내용**

판별식이 0 이상일 때만 제곱근과 두 근을 계산하도록 변경했다. 숫자가 아닌 입력과 실수 비교 기준은 추가 검토가 필요하다.


## 3번. 최대공약수와 최소공배수

### 과제 요구사항

두 정수의 최대공약수와 최소공배수를 출력한다. 제출 코드는 유클리드 호제법의 재귀를 사용한다.

### 구현 시 필요한 OOP 및 C++ 개념

재귀 함수, 나머지 연산, 정수 범위와 형 변환. 현재 클래스는 없다.

### 구현 시 유의사항

0과 음수의 입력 허용 여부를 원문 명세에서 확인하고, 곱셈 오버플로를 검사한다.

### 개선 및 보완

두 입력이 0이면 현재 최소공배수 계산에서 0으로 나누게 된다. 부호와 0 처리, 자료형 일관성을 정하고 LCD 표기를 일반적인 LCM으로 정리할 수 있다.

**수정본에 반영한 내용**

두 수 중 하나라도 0이면 최소공배수를 0으로 처리하고, 곱셈 전에 최대공약수로 나누도록 순서를 변경했다. 음수와 정수 범위는 추가 확인이 필요하며 출력 표기 `LCD`는 그대로다.


## 4번. 3×3 역행렬

### 과제 요구사항

3×3 행렬을 입력받아 여인수 행렬의 전치와 행렬식을 이용해 역행렬을 출력한다. 역행렬이 없으면 그 사실을 표시한다.

### 구현 시 필요한 OOP 및 C++ 개념

2차원 배열, 행렬식, 함수 분리, 실수 연산. 현재 클래스는 없다.

### 구현 시 유의사항

여인수의 부호와 전치 인덱스를 확인하고, 행렬식이 0 또는 매우 작은 경우의 수치 오차를 고려한다.

### 개선 및 보완

행렬 원소는 double이지만 det는 int여서 소수 행렬식이 잘린다. det를 double로 바꾸고 단위행렬, 소수 원소, 특이 행렬로 확인한다.

**수정본에 반영한 내용**

행렬식 `det`의 자료형을 `int`에서 `double`로 변경했다. 소수 행렬식이 정수로 잘리는 문제를 수정했다.


## 라이브러리 사용에 관한 변경

3번에서 사용하던 `swap`을 직접 작성한 `swapValues` 함수로 교체했다. 나머지 입출력·수학 헤더는 유지했다. 원래 사용하던 입출력·수학 및 파일 처리 헤더는 유지하며 정확한 제한 범위는 과제 명세로 확인해야 한다.
