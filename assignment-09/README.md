## 1번. 할인 가격과 다형성

### 과제 요구사항

두 가격과 할인율을 입력받아 기존 비교 흐름대로 할인 대상과 절약액을 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

상속, 가상 함수, 오버라이딩과 연산자 오버로딩.

### 구현 시 유의사항

할인율은 숫자 또는 끝에 %를 붙여 입력한다. 0~100 범위이며 가격은 음수가 아니어야 한다. 비교의 의미는 원래 명세가 없어 기존 동작을 유지했다.

### 개선 및 보완

**수정본에 반영한 내용**

string과 stod를 제거하고 문자 배열과 strtod를 사용했다. 입력값·유한값을 검사하고 기반 클래스 소멸자를 virtual로 변경했다.

## 2번. 사람·학생·교수 클래스

### 과제 요구사항

역할을 입력받아 Person 포인터로 Student 또는 Professor의 Say를 호출한다.

### 구현 시 필요한 OOP 및 C++ 개념

추상 클래스, 순수 가상 함수와 동적 바인딩.

### 구현 시 유의사항

student 또는 professor를 입력한다. 현재 예제의 인물 정보는 코드에 지정된 값이다.

### 개선 및 보완

**수정본에 반영한 내용**

문자 배열을 사용하고 잘못된 역할에서 null 포인터를 호출하지 않도록 했다. Person 소멸자를 virtual로 변경했다.

## 3번. 행렬 연산자 오버로딩

### 과제 요구사항

3×3 행렬의 +=, -=, * 연산 결과를 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

연산자 오버로딩과 값 반환.

### 구현 시 유의사항

각 원소가 1인 행렬과 2인 행렬을 사용하는 고정 예제이다.

### 개선 및 보완

**수정본에 반영한 내용**

계산 과정을 검사했으며 세 중첩 반복문의 수동 행렬 곱을 유지했다. 제한된 라이브러리 호출은 없다.

## 4번. 평균 점수 양방향 리스트

### 과제 요구사항

각 학생의 평균을 정렬 삽입한 뒤 정방향과 역방향으로 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

양방향 연결 리스트, 객체 소유권과 소멸자.

### 구현 시 유의사항

입력은 코드의 고정 점수 예제를 사용한다.

### 개선 및 보완

**수정본에 반영한 내용**

정렬 삽입과 양방향 연결을 확인하고 null 삽입을 거부했다. 소유 노드를 이중 해제할 수 있는 기본 복사를 금지했다.

## 빌드 및 확인

각 문제를 독립 실행 파일로 빌드한다. 같은 문제의 모든 .cpp를 함께 컴파일하고, 다른 문제의 소스는 섞지 않는다. 표준 컨테이너와 `<algorithm>`, `<utility>`, `<numeric>` 헤더는 사용하지 않는다. 입출력, C 문자열·숫자 변환, 수학, 예외 처리는 사용한다. 9차 4문제는 Visual Studio 2022 C++17로 빌드하고 대표 실행 사례를 확인했다. 전체 입력 영역의 정확성을 보장하는 것은 아니다.
