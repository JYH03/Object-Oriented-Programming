## 1번. 좌표 회전 변환

### 과제 요구사항

각도를 입력받아 보고서의 변환 행렬을 구성하고 좌표에 곱해 회전 변환한다.

### 구현 시 필요한 OOP 및 C++ 개념

행렬과 벡터 연산, 삼각함수, 도에서 라디안으로의 변환. 현재 클래스는 없다.

### 구현 시 유의사항

sin과 cos는 라디안을 사용한다. 출력 자릿수와 행렬 곱 순서는 원래 명세를 따른다.

### 개선 및 보완

π와 반올림 처리의 정밀도를 검토하고 0°, 90°, 180° 등으로 확인한다.

**수정본에 반영한 내용**

실행 코드는 유지하고 주석을 정리했다. 수치 정밀도는 추가 확인이 필요하다.


## 2번. 전압 및 전력 비율 계산

### 과제 요구사항

전원 전압과 저항값으로 부하 유무에 따른 전압을 구하고, 부하가 있으면 전체 전력 대비 부하 전력의 비율을 계산한다.

### 구현 시 필요한 OOP 및 C++ 개념

조건문, 직렬·병렬 저항, 유리수와 순환소수 표현. 현재 클래스는 없다.

### 구현 시 유의사항

분모가 0이 되는 입력, 부하가 없다는 표시의 의미, 소수 출력 규칙을 원문과 대조한다.

### 개선 및 보완

회로 계산과 순환소수 출력 코드를 분리하고 유한소수, 순환소수, 경계 입력을 검증한다.

**수정본에 반영한 내용**

최대공약수 재귀 호출 결과를 반환하고, 부하 전력/전체 전력의 백분율을 계산하도록 수정했다. 혼합 순환소수의 중간 계산에서 잘못 참조하던 값을 고쳤다. 전체 입력과 순환소수 출력은 추가 검증이 필요하다.


## 3번. 진법 변환

### 과제 요구사항

10진법을 입력받아 목표 진법으로 변환한다. 2·8·16진법 변환을 구현하며 역변환도 가능하여야 한다.

### 구현 시 필요한 OOP 및 C++ 개념

문자열, 자리값, 나눗셈과 나머지, 정수 범위. 현재 클래스는 없다.

### 구현 시 유의사항

진법에 없는 숫자, 0, 16진수 문자, 큰 값의 범위를 확인한다. 

### 개선 및 보완

입력 유효성 검사와 변환 과정의 오버플로 검사를 추가하고 양방향 경계 사례를 점검한다.

**수정본에 반영한 내용**

10진수 0을 2진수로 변환할 때 `0`을 출력하도록 수정했다. 입력 유효성 및 오버플로 검사는 아직 남아 있다.


## 4번. 정렬과 중앙값

### 과제 요구사항

수를 입력받아 버블·삽입·병합·퀵 정렬을 구현하고 정렬 결과와 중앙값을 출력한다. 보고서에서는 시간 복잡도와 시간 측정도 다룬다.

### 구현 시 필요한 OOP 및 C++ 개념

배열, 함수, 재귀, 정렬 알고리즘과 시간 복잡도. 현재 클래스는 없다.

### 구현 시 유의사항

정렬별로 같은 입력을 사용하고, 짝수 개일 때 중앙값 기준과 시간 측정 단위를 명세에서 확인한다. 이 문제는 `windows.h`와 Windows 성능 카운터를 사용하므로 Windows에서 빌드한다.

### 개선 및 보완

중복값, 이미 정렬된 배열, 역순, 최소 개수를 테스트하고 네 정렬의 결과를 비교한다.

**수정본에 반영한 내용**

값 교환을 직접 작성한 함수로 변경하고 주석을 정리했다. 정렬별 결과와 짝수 개의 중앙값 기준은 추가 확인이 필요하다.


## 라이브러리 사용에 관한 변경

2번과 4번에서 사용하던 `swap`을 직접 작성한 `swapValues` 함수로 교체했다. 4번의 `sort`는 표준 함수가 아닌 직접 선언한 배열 이름이다. 원래 사용하던 입출력·수학 및 파일 처리 헤더는 유지하며 정확한 제한 범위는 과제 명세로 확인해야 한다.
