## 1번. 중첩 배열 조회

### 과제 요구사항

중첩된 배열 형태의 문자열을 입력받고 arr 또는 arr[3][2] 같은 명령으로 전체나 지정 위치를 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

문자열 파싱, 중첩 구조와 인덱스.

### 구현 시 유의사항

괄호 짝, 인덱스 범위, 잘못된 명령과 입력 길이를 확인한다.

### 개선 및 보완

종료 조건과 범위 검사를 추가하고 중첩 배열을 별도 자료구조로 파싱하는 방식을 검토한다.

## 2번. 생성자와 소멸자

### 과제 요구사항

클래스 A의 생성자에 값을 전달해 private 멤버에 저장하고, 생성과 소멸 시 해당 값을 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

클래스, public/private, 생성자·소멸자, 객체 수명, 헤더와 구현 파일.

### 구현 시 유의사항

main.cpp와 A.cpp를 함께 빌드한다. 객체 생성과 스코프 종료 시점을 구분한다.

### 개선 및 보완

입력 실패를 처리하고 초기화 목록을 활용하는 방식을 검토한다.

## 3번. CSVLoader

### 과제 요구사항

클래스로 파일을 읽어 숫자 데이터를 2차원 형태로 저장하고 행·열 수와 데이터를 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

캡슐화, 생성자와 소멸자, 동적 할당, 파일 입출력, 객체 복사와 소유권.

### 구현 시 유의사항

main.cpp와 CSVLoader.cpp를 함께 빌드하고 실행 작업 폴더에 CSVLoader_Data.txt를 둔다. 데이터 형식은 제공 파일을 기준으로 확인한다.

### 개선 및 보완

현재 생성자와 parse가 path 인자를 받지만 파일명을 고정해 사용한다. 파일 열기 실패, 행·열 범위, 재호출 시 기존 메모리와 복사 시 소유권을 개선한다.

## 4번. 시계 클래스

### 과제 요구사항

초 단위 입력을 시·분·초로 바꾸고 시·분·초를 각각 증가시킨다. 생성·소멸 과정과 시간 출력을 확인한다.

### 구현 시 필요한 OOP 및 C++ 개념

클래스, 멤버 함수, public/private, 생성자와 소멸자.

### 구현 시 유의사항

main.cpp와 Clock.cpp를 함께 빌드한다. 59초·59분·23시의 올림과 초기화 순서를 확인한다.

### 개선 및 보완

현재 setSecond와 setMinute가 초기화 전 멤버를 읽을 수 있다. 멤버를 먼저 초기화하고 시간 설정을 안전하게 재구성하며 경계값을 검증한다.
