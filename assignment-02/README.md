## 1번. 숫자 빈도 세기

### 과제 요구사항

두 숫자 문자열을 이어서 왼쪽부터 각 숫자가 처음 나타난 순서로 숫자와 그 빈도를 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

문자열과 문자 배열, 반복문, 빈도 계산. 현재 클래스는 없다.

### 구현 시 유의사항

앞의 0을 보존하고, 반복 횟수가 한 자릿수를 넘는 경우와 배열 길이 제한을 고려한다.

### 개선 및 보완

고정 크기 배열과 중복 처리 과정을 점검하고 정수형 빈도 계산을 검토한다.

**수정본에 반영한 내용**

원본의 문자 배열과 `<cstring>`을 사용하면서 연결 배열 크기를 늘리고 빈도를 정수로 세어 범위 초과와 10회 이상 출현 시 개수 오출력을 수정했다.


## 2번. 오류 검출과 FCS

### 과제 요구사항

12비트 데이터를 받아 4비트 FCS를 만들고 오류를 발생시킨 뒤 XOR 연산으로 오류 여부를 확인한다.

### 구현 시 필요한 OOP 및 C++ 개념

비트 연산, XOR, 시프트와 이진수 표현. 현재 클래스는 없다.

### 구현 시 유의사항

생성 다항식과 나머지의 판정 규칙은 원래 문제 명세와 대조해야 한다. 입력 길이와 반복 종료 조건을 확인한다.

### 개선 및 보완

보고서에서 재구성 데이터와 오류 문구가 출력되지 않고 반복문이 끝나지 않는 문제가 있었다. 나눗셈 과정과 종료 조건을 추적하고 정상·오류 입력으로 검증한다.

**수정본에 반영한 내용**

지역 배열 주소 반환과 나눗셈 과정의 오류를 없애도록 XOR 나머지 계산을 다시 작성하고, 수신 프레임의 나머지가 0인지 확인한다. 12비트 이진 입력도 검사한다. 생성 다항식 `11011`과 결과 형식은 원래 명세와 대조가 필요하다.


## 3번. 와일드카드 파일명 검색

### 과제 요구사항

파일명 목록과 검색 패턴을 비교한다. ?는 문자 하나, *는 길이에 관계없는 문자열과 대응한다.

### 구현 시 필요한 OOP 및 C++ 개념

문자열 인덱스, 패턴 매칭, 분기와 반복문. 현재 클래스는 없다.

### 구현 시 유의사항

빈 문자열과 연속된 `*` 및 `?`의 조합, 문자열 끝을 벗어나는 인덱스를 주의한다.

작업 폴더에 `filenames.txt`를 만들고 한 줄에 파일명 하나를 적는다. 예를 들어 `abc`, `ac`, `xyz`를 각각 한 줄에 적은 뒤 `filenames.txt 1`과 `a*c`를 순서대로 입력하면 `abc`와 `ac`가 출력된다.

### 개선 및 보완

보고서에는 일부 * 조합이 완벽하지 않고 조건문이 복잡하다고 적혀 있다. 매칭 함수를 분리하고 빈 문자열, 연속 와일드카드 테스트를 추가한다.

**수정본에 반영한 내용**

`?`와 `*`를 처리하는 매칭 함수를 작성하고 파일을 읽지 못하면 종료하도록 변경했다. `a*c`가 `abc`, `ac`, `abbbc`와 일치하는 사례를 확인했다.


## 4번. 이미지 자르기와 반전

### 과제 요구사항

원본 이미지에서 두 좌표 사이 영역을 자르고 좌우 및 상하 반전 이미지를 생성한다.

### 구현 시 필요한 OOP 및 C++ 개념

포인터, 동적 메모리, 파일 입출력과 픽셀 인덱스. 현재 클래스는 없다.

### 구현 시 유의사항

실행 폴더에 512×512 크기의 8비트 회색조 RAW 파일을 둔다. 파일명 입력 후 좌표를 `0,0`과 `256,192`처럼 입력한다. 좌표는 0부터 시작하고 두 번째 좌표는 잘라낼 범위에 포함하지 않는다. 파일이 실제로 존재하는지와 좌표가 이미지 범위 안에 있는지 확인한 뒤 실행한다.

실행하면 파일명에 `_cropped_`, `_horizontalflip`, `_verticalflip`이 붙은 RAW 결과가 생성된다.

### 개선 및 보완

좌표 검증과 파일·메모리 오류 처리를 보완하고 자르기와 각 반전을 독립적으로 확인한다.

**수정본에 반영한 내용**

새 출력 파일을 열기 전에 이전 출력 파일을 닫도록 수정했다. 파일 열기 실패와 좌표 범위 검사는 아직 남아 있다.


## 라이브러리 사용에 관한 변경

1~3번은 표준 컨테이너 대신 문자 배열을 사용한다. 2번은 원본과 같이 `rand`를 사용한다. 4번의 좌표 교환은 직접 작성한 `swapValues`로 변경했다. 원래 사용하던 입출력·수학 및 파일 처리 헤더는 유지하며 정확한 제한 범위는 과제 명세로 확인해야 한다.
