## 1번. 숫자 빈도 세기

### 과제 요구사항

두 숫자 문자열을 이어서 왼쪽부터 각 숫자가 처음 나타난 순서로 숫자와 그 빈도를 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

문자열과 문자 배열, 반복문, 빈도 계산. 현재 클래스는 없다.

### 구현 시 유의사항

앞의 0을 보존하고, 반복 횟수가 한 자릿수를 넘는 경우와 배열 길이 제한을 고려한다.

### 개선 및 보완

고정 크기 배열과 중복 처리 과정을 점검하고 정수형 빈도 배열 및 std::string 사용을 검토한다.

## 2번. 오류 검출과 FCS

### 과제 요구사항

12비트 데이터를 받아 4비트 FCS를 만들고 오류를 발생시킨 뒤 XOR 연산으로 오류 여부를 확인한다.

### 구현 시 필요한 OOP 및 C++ 개념

비트 연산, XOR, 시프트와 이진수 표현. 현재 클래스는 없다.

### 구현 시 유의사항

생성 다항식과 나머지의 판정 규칙은 원래 문제 명세와 대조해야 한다. 입력 길이와 반복 종료 조건을 확인한다.

### 개선 및 보완

보고서에서 재구성 데이터와 오류 문구가 출력되지 않고 반복문이 끝나지 않는 문제가 있었다. 나눗셈 과정과 종료 조건을 추적하고 정상·오류 입력으로 검증한다.

## 3번. 와일드카드 파일명 검색

### 과제 요구사항

파일명 목록과 검색 패턴을 비교한다. ?는 문자 하나, *는 길이에 관계없는 문자열과 대응한다.

### 구현 시 필요한 OOP 및 C++ 개념

문자열 인덱스, 패턴 매칭, 분기와 반복문. 현재 클래스는 없다.

### 구현 시 유의사항

빈 문자열과 연속된 * 및 ?의 조합, 문자열 끝을 벗어나는 인덱스를 주의한다.

### 개선 및 보완

보고서에는 일부 * 조합이 완벽하지 않고 조건문이 복잡하다고 적혀 있다. 매칭 함수를 분리하고 빈 문자열, 연속 와일드카드 테스트를 추가한다.

## 4번. 이미지 자르기와 반전

### 과제 요구사항

원본 이미지에서 두 좌표 사이 영역을 자르고 좌우 및 상하 반전 이미지를 생성한다.

### 구현 시 필요한 OOP 및 C++ 개념

포인터, 동적 메모리, 파일 입출력과 픽셀 인덱스. 현재 클래스는 없다.

### 구현 시 유의사항

실제 이미지 형식과 크기, 픽셀 배치, 좌표 범위와 파일 열기 실패를 확인한다. 실행에 필요한 원본 이미지와 명세는 별도로 확인한다.

### 개선 및 보완

좌표 검증과 파일·메모리 오류 처리를 보완하고 자르기와 각 반전을 독립적으로 확인한다.
