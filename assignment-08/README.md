## 1번. 연결 리스트 정렬과 검색

### 과제 요구사항

0~200의 서로 다른 난수 16개를 만들고 내림차순 정렬 후 이진 탐색과 가까운 값 선택을 수행한다.

### 구현 시 필요한 OOP 및 C++ 개념

구조체, 연결 리스트, 참조 매개변수와 탐색.

### 구현 시 유의사항

입력값과 결과는 난수에 따라 달라진다. 연결 리스트는 인덱스 접근이 O(n)이므로 탐색 전체가 배열의 O(log n)과 같지는 않다.

### 개선 및 보완

**수정본에 반영한 내용**

정렬로 바뀐 head를 호출자에게 돌려주도록 참조로 받는다. 종료 시 노드를 해제하고 목표값과 차이를 넓은 정수로 계산해 오버플로를 줄인다. 가까운 값 선택 규칙은 기존 코드를 유지한다.

## 2번. 음악 정보 클래스

### 과제 요구사항

제목,가수,앨범,연도,트랙번호를 읽어 클래스에 저장하고 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

캡슐화, 문자 배열, getter와 setter.

### 구현 시 유의사항

main.cpp와 myMusic.cpp를 함께 빌드한다. 문자열 필드는 255자 이하이며 쉼표가 포함된 따옴표 CSV는 지원하지 않는다.

### 개선 및 보완

**수정본에 반영한 내용**

누락된 myMusic.h를 작성하고 string·sstream을 제거했다. 문자열을 경계 안에서 복사하고 입력 형식 실패를 처리한다.

## 3번. 가수와 곡 연결 리스트

### 과제 요구사항

Music_Info.txt에서 가수와 곡을 읽고 가수별로 정렬된 곡을 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

원형 연결 리스트, 중첩 연결 리스트와 동적 메모리.

### 구현 시 유의사항

문제 폴더에 포함된 [Music_Info.txt](./3번/Music_Info.txt)는 실행 확인용 예제다. `가수/곡 제목`을 한 줄에 하나씩 적거나, `/` 뒤에 구분 정보와 탭을 넣고 곡 제목을 적는다. 작업 폴더에서 실행하며 한 줄은 4095자 이하로 입력한다.

### 개선 및 보완

**수정본에 반영한 내용**

문자 배열로 파싱하며 원형 리스트를 한 바퀴만 순회한다. 모든 가수·곡 노드를 해제하고, 제목의 대소문자 때문에 일부 곡을 출력에서 누락하던 동작을 제거했다.

## 4번. 연결 다항식의 합과 차

### 과제 요구사항

두 다항식을 읽어 같은 차수의 항을 합치고 합과 차를 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

연결 노드, 정렬 삽입, 소멸자와 복사 제한.

### 구현 시 유의사항

main.cpp와 PolyTerm.cpp를 함께 빌드한다. 정수 계수·정수 지수와 x 표기를 지원하며 한 줄은 4095자 이하이다.

### 개선 및 보완

**수정본에 반영한 내용**

누락된 PolyTerm.h를 작성하고 stringstream/stoi 대신 문자별로 파싱한다. 마지막 항의 중복 삽입을 방지하고 결과가 0이면 0을 출력한다. 자기 자신과의 덧셈·뺄셈과 계수 범위 검사를 처리한다.

## 빌드 및 확인

각 문제를 독립 실행 파일로 빌드한다. 같은 문제의 모든 .cpp를 함께 컴파일하고, 다른 문제의 소스는 섞지 않는다. 표준 컨테이너와 `<algorithm>`, `<utility>`, `<numeric>` 헤더는 사용하지 않는다. 입출력, C 문자열·숫자 변환, 수학, 예외 처리는 사용한다. 8차 4문제는 Visual Studio 2022 C++17로 빌드하고 대표 실행 사례를 확인했다. 전체 입력 영역의 정확성을 보장하는 것은 아니다.
