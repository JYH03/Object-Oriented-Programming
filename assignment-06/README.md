## 1번. 직원 정보 관리 미완성 코드

### 과제 요구사항

보고서가 없어 정확한 요구사항은 확인할 수 없다. 코드에는 직원 정보와 연결 목록, insert·print·change·find 명령을 구현하려는 흔적이 있다.

### 구현 시 필요한 OOP 및 C++ 개념

클래스와 캡슐화, 생성자, 포인터, 연결 리스트, 객체 수명과 메모리 소유권.

### 구현 시 유의사항

Employee.h와 철자가 Empoloyee.cpp인 구현 파일을 함께 확인한다. 문자열 포인터의 수명과 연결 노드 해제가 중요하다.

### 개선 및 보완

Empoloyee.cpp에는 미완성 문장과 빈 함수가 있고 선언된 함수 일부의 구현도 확인되지 않는다. 현재 그대로는 빌드가 완료되지 않는다. 명세 확인 후 초기화·저장·검색·수정·정리 기능을 구현하고 테스트한다.
