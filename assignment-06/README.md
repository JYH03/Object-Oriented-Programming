## 1번. 직원 정보 관리

### 과제 요구사항

제공된 예제를 기준으로 최대 10명의 이름, 나이, 국가, 직업을 관리한다. `insert`는 등록하고 `find`는 이름으로 검색한다. `change`는 이름으로 찾은 직원의 정보를 변경하고 `print`는 등록 순서대로 출력한다. `exit` 또는 입력 종료 시 프로그램을 끝낸다.

### 구현 시 필요한 OOP 및 C++ 개념

클래스와 캡슐화, 생성자·소멸자, 깊은 복사, 복사 대입, 포인터 배열과 동적 메모리 소유권.

### 구현 시 유의사항

`main.cpp`와 `Empoloyee.cpp`를 함께 빌드한다. 이름·국가·직업은 공백 없이 입력한다. 같은 이름이 여러 번 등록되면 `find`와 `change`는 먼저 등록된 직원에게 적용한다.

```text
insert Alice 20 Korea Engineer
find Alice
change Alice Carol 21 Korea Student
print
exit
```

### 개선 및 보완

**수정본에 반영한 내용**

직원을 10칸 포인터 배열에 저장하고 검색 함수를 재사용한다. 입력 길이와 정수 범위를 검사하고, 입력이 끝나면 생성한 직원 객체를 각각 해제한다. `Employee`는 문자열을 직접 소유하며 복사 생성자와 복사 대입에서 깊은 복사를 수행한다. 정보 변경 시 새 문자열을 모두 준비한 후 기존 문자열을 교체한다.

## 2번. 학생과 학교 클래스

### 과제 요구사항

학생을 등록하고 이름순으로 정렬하며 전체 또는 특정 반을 출력한다.

### 구현 시 필요한 OOP 및 C++ 개념

캡슐화, 생성자·소멸자, 동적 배열과 복사 제한.

### 구현 시 유의사항

최대 100명, 이름·반은 공백 없는 49자 이하로 입력한다. main.cpp만 빌드한다.

### 개선 및 보완

**수정본에 반영한 내용**

문자 배열과 직접 교환을 사용한다. 용량과 메모리 소유권을 검사하고 얕은 복사를 금지한다. 이름 정렬·반 조회를 확인했다.

## 3번. 문자열 클래스

### 과제 요구사항

assign, at, c_str, clear, push_back, compare, replace, substr, find와 숫자 변환을 확인한다.

### 구현 시 필요한 OOP 및 C++ 개념

깊은 복사, 대입 연산자, 생성자·소멸자, namespace와 예외.

### 구현 시 유의사항

main.cpp와 oopstd.cpp를 함께 빌드한다. 다른 과제의 oopstd.h와 혼합하지 않는다. 헤더와 구현은 앞서 제공된 사용 예제를 기준으로 작성한 것이다.

### 개선 및 보완

**수정본에 반영한 내용**

표준 문자열 컨테이너 대신 char 배열을 사용한다. 복사·자기 자신을 참조하는 치환과 범위를 처리한다. 숫자 변환은 strtol/strtof를 사용한다. 표준 string 전체 기능을 구현한 것은 아니다.

## 4번. 행렬 클래스

### 과제 요구사항

행렬식, 상수 연산, 행렬 합·차·곱, 전치·수반행렬·역행렬을 계산한다.

### 구현 시 필요한 OOP 및 C++ 개념

동적 2차원 배열, 복사 생성자·대입 연산자, 예외와 참조.

### 구현 시 유의사항

main.cpp와 ooplinalg.cpp를 함께 빌드한다. 정사각형 여부와 차원, 특이 행렬을 확인한다. float 기반이므로 조건이 나쁜 행렬의 수치 오차는 남아 있다.

### 개선 및 보완

**수정본에 반영한 내용**

delete[]와 깊은 복사, 직사각형 곱셈·전치, 차원 검사를 적용한다. 역행렬은 수반행렬 반복 계산 대신 부분 피벗 가우스-조던 소거법으로 O(n³)에 구한다.

## 빌드 및 확인

각 문제를 독립 실행 파일로 빌드한다. 같은 문제의 모든 .cpp를 함께 컴파일하고, 다른 문제의 소스는 섞지 않는다. 표준 컨테이너와 `<algorithm>`, `<utility>`, `<numeric>` 헤더는 사용하지 않는다. 입출력, C 문자열·숫자 변환, 수학, 예외 처리는 사용한다. Visual Studio 2022 C++17로 빌드했다. 1번은 추가·검색·변경·출력, 인원 제한, 잘못된 입력, EOF, 복사 생성 및 대입을 확인했다.
